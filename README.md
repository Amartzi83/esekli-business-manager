# עסקלי — תצוגת ניהול העסק

דף הבית הוא אבטיפוס רספונסיבי בעברית. כרגע הנתונים בדף הם להמחשה בלבד.

## אירוח פרטי

הדף מוגש דרך `server.js`, שמחזיר רק את `index.html` ולא חושף קבצים אחרים. לפרסום פרטי משתמשים ב־Google Cloud Run עם Identity-Aware Proxy (IAP), שמאמת כל בקשת דפדפן לפני שהשרת שולח את קובצי האתר.

הגדרות הפריסה:

- אזור: `me-west1` (תל אביב)
- שירות: `esekli-private-site`
- חובה להפעיל IAP ולהשאיר גישה אנונימית כבויה
- יש להעניק למשתמשים המורשים את תפקיד IAP-secured Web App User
- אין לפרוס את אותו דף ב־Firebase Hosting אם נדרשת הגבלת גישה לפני טעינת הקבצים

פריסת Cloud Run דורשת חשבון Cloud Billing פעיל. השרת מוגדר בחיוב לפי בקשות, אך שימוש בענן ובנייה עשויים לחרוג ממכסות חינם וליצור חיובים.
